# 隔离授权与密钥

- 写入命令要求 root、Ubuntu 24.04、systemd、独立 VM、明确的 `--confirm`，以及管理员在 `/etc/ipsecvpn/lab-authorized` 放置内容为 `ipsecvpn-lab-v1` 加换行的实验授权文件。该文件使用 root:root 和 `0600`，父目录使用 `0700`。标记记录操作者的授权，实际网络隔离由 VM 环境保证。
- `apply --confirm` 从 `/etc/ipsecvpn/profiles/` 直接读取 root 所有的 `0600` YAML。每条链路的 PSK 文件位于 root 所有的 `0700` 密钥目录，文件为独占硬链接计数 1 的普通文件，权限 `0600`。使用 `openssl rand -hex 32` 生成每条链路各自的 64 字符小写十六进制 PSK。对端以该文本作为 PSK，通过独立受控渠道交付。
- 文件路径逐级检查。凭据从受控文件读入，在 `/run/ipsecvpn/` 下生成 root 专用临时 swanctl 配置，由 VICI 导入后立即清理。进程参数、错误输出和公开渲染均省略密钥内容。备份保存引用和摘要，恢复时校验原文件。
- 命令参数按数组传递，预检严格检查接口、站点、IKE ID 和 CIDR。现有 SA、未知服务配置和冲突对象会阻止继续。Ubuntu 软件包来自隔离 VM 中预先审查的 apt 来源，安装模拟拒绝升级或移除既有包。
- 示例和验收仅使用虚构 IPv4 地址与随机实验密钥。轮换、生产授权、场馆对接及上游防火墙开放由各方管理员在后续验收中核对。
